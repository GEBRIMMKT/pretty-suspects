# Pretty Suspects — Case 001: The Last Party

Apresentação interativa do projeto **A2 — Projeto Baralho Tipográfico** (Design, IDP): um jogo de investigação com cinco cartas, apresentado como lançamento de marca.

**Four friends. One dead. Three suspects.**

- Site: abra o link do GitHub Pages deste repositório (em *About*, à direita).
- Modo apresentação: botão **PRESENTATION MODE** na abertura. Setas avançam e voltam, `M` abre o menu, `F` liga a tela cheia e `Esc` sai.
- A revelação final fica lacrada até a turma travar a acusação.

Guia completo para o grupo (trocar imagens, editar textos, votação e revelação): [LEIA-ME.md](LEIA-ME.md).

Projeto acadêmico fictício. As personagens não representam características reais das integrantes. As referências visuais pertencem aos seus autores e foram usadas só como inspiração.
